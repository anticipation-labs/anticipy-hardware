# Strict-envelope package note

The inherited firmware README describes the earlier 250 mAh prototype. This strict 56 × 23 × 12 mm enclosure instead models a **protected 200 mAh 502025 pack**.

At an 85% usable-capacity assumption, a 16-hour run requires sealed-unit average current at or below **10.625 mA**. The host check's 13.28 mA number applies only to 250 mAh and must not be used for this enclosure.

No battery runtime has been physically tested. The UF2 remains lab-only because stored audio is plaintext and the iPhone path has not been run.
