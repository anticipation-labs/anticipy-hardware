# Anticipy v1.3 — start here

This folder contains one stronger, hand-assembled prototype enclosure.  It is
not the old fit-gauge plate.  The print plate contains exactly three named
objects: `ANTICIPY_BASE`, `ANTICIPY_LID`, and `ANTICIPY_BUTTON`.

## The simple plan

1. Order the controlled parts in `02_GUIDES/ORDER_NOW.csv`.
2. Print `01_PRINT/PRINT_THIS_ONE_UNIT_P2S.3mf` with the settings in
   `02_GUIDES/PRINT_SETTINGS.md`.
3. Dry-fit every unpowered part.  Do not force or bend the pouch battery.
4. Have an adult perform the soldering and battery work using
   `02_GUIDES/ASSEMBLY_LIKE_IM_2.md`.
5. Run the open-case audio, storage, Bluetooth, haptic, charge and 16-hour
   runtime tests before closing the lid.

## Size and weight

- Electronics body: 68 x 33 x 16.5 mm
- Including the reinforced printed loop: 72 x 33 x 16.5 mm
- Digital mass estimate: about 33.4 g; 38.4 g with 15% uncertainty

The digital files were checked for fit and printability.  A computer check
cannot prove battery runtime, microphone quality, radio range, drop survival or
water resistance.  Those are physical test gates.
