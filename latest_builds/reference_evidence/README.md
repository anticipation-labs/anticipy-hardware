# Retained component reference evidence

These files were used in the USB protection and component review, but were omitted from the smaller email handoff. They are included here separately so the E1P1 handoff remains byte-for-byte identical to its verified archive.

Use [the canonical release decisions](../E1P1/pcb/verification/Component_Release_Decisions.json) and the [final BOM](../E1P1/pcb/manufacturing/Machine_Assembly_BOM.csv) for selected parts. The copy of Component_Release_Decisions.json under engineering_decisions preserves earlier analysis. Files named Original describe the earlier circuit/footprint comparison, not an alternative PCB to manufacture.

Some reports retain local paths from the original build computer. Their component_source_evidence references correspond to the files in this directory. These references do not change the native PCB, schematic or manufacturing outputs.
