# Anticipy decision card

## Like you are two

The ready-made boards make a **bigger test toy**. The small customer pendant needs **one special green board** made for it. We print and test the big one first, then order only three little boards, test them, and only then make the customer batch.

## Locked decisions

| Question | Answer |
|---|---|
| Can the no-custom-PCB build work? | Yes, as a 66.2 × 27.2 × 14.2 mm lab unit |
| Can it be PLAUD-size? | No; ready-made boards and hand wiring are too wide and tall |
| Does the customer version need a PCB? | Yes |
| Does the exact-size CAD fit? | Yes digitally: 50.5 × 20.68 × 10.8 mm |
| Is it ready to order 50? | No; route and test three EVT units first |
| Can 20 hours fit locally? | Yes: 414 MB required; 4-Gbit managed SD NAND exposes about 481 MB |
| Can 200 mAh last 16 hours? | Plausible only if the sealed average is ≤10.625 mA; measure it |
| What is the final skin? | Polycarbonate chassis plus brushed/anodized aluminum face |
| What do we print today? | PLA Silk+ lab shell and fit gauges |

## The shortest safe production ladder

1. Print one shell and prove fit.
2. Assemble one lab recorder and prove the complete data path.
3. Finish/rule-check the custom PCB.
4. Assemble three EVT units.
5. Run the included tests.
6. Fix anything found.
7. Build 10, then 35, then the sellable lot.

Skipping step 4 does not make the schedule faster. It turns 50 boards into one expensive experiment.
