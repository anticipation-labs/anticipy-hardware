# PRESS PRINT — 3 steps

1. **Double-click `PRINT_ME_anticipy_all8.3mf`** (also copied to your Desktop).
   It opens in Bambu Studio with all 8 halves already arranged, flat side down.
   (If it asks: machine = your printer, plate = Textured PEI.)

2. **Pick settings** (30 seconds):
   - Filament: **Bambu PLA Metal — Iron Gray Metallic**
   - Process: **0.16mm Optimal**, turn ON "Ironing → Top surfaces",
     Walls = 5, top shell layers = 7, infill 15% gyroid
     — or just File → Import → Import Configs → `anticipy_process.json`
     (this folder) and pick "Anticipy pendant" in the Process dropdown.
   - Then: select all objects → Adaptive layer height (smooth, min 0.08).
   - (These exact settings were actually slice-verified: **3 h 01 m**, 74 g.)

3. **Slice → Print.** No supports, no brim, don't rotate anything.
   Use an X1C/P1S-class plate if you have the choice — everything fits an
   A1 mini too, but that one lands just over 4 h with startup.

4. **After printing, 2 minutes:** run a needle file once through the USB
   opening and around its rim (kills bridge-sag + one feather edge), and
   rub each half's flat glue face flat on 220-grit sandpaper (figure-8,
   3 strokes) before assembly.

While it prints, grab: flush cutters, kapton tape, a 3 mm-thick soft foam
strip, double-sided tape, gel CA glue, 2 short bits of spare filament, and a
USB-C cable you don't care about. Then follow **README.md → Assembly**
(15 min, rehearse dry first).

Print V1's two halves first off the plate if you want to test-fit before
committing glue: V1 = the pair WITHOUT the extra-deep back and with normal
holes (labeled in the plate view; V3 is the obviously-deeper one).
